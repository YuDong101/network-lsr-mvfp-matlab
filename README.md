# Network LSR / MVFP Simulation Code

This repository contains MATLAB code for numerical simulations and analysis of a network logical stochastic resonance (LSR) model. The code includes:

- an AND-gate network simulation driven by noise and global coupling;
- a mean-field Fokker–Planck (MVFP) analysis of a bistable system;
- readout curves, effective potentials, bifurcation diagrams, and mean first-passage time (MFPT) calculations.

## Contents

| File | Purpose |
| --- | --- |
| `main.m` | Runs the network AND-gate parameter scan over noise intensity `D` and global coupling `g`, then saves the probability matrix, a text table, and a heat map. |
| `trial_tot.m` | Function called by `main.m`. Simulates `N` bistable units under a seven-stage input sequence and returns the success indicator for each unit and trial. |
| `mvfp_a.m` | Runs the MVFP analysis, including density evolution, finite-time readout, steady-state branches, effective potentials, `x-P0` bifurcation, MFPT versus `P0`, and MFPT versus `D`. Helper functions are defined at the end of this file. |

## Requirements

- MATLAB with standard numerical and plotting functionality.
- Parallel Computing Toolbox is recommended for `main.m`, which uses `parfor`. If the toolbox is unavailable, replace `parfor` with `for` in `main.m` or adapt the loop to the available MATLAB configuration.
- No external MATLAB toolbox or downloaded data file is required by the three scripts in this directory.

## Quick start

Run the MVFP analysis first if you want the figures and data associated with the mean-field model:

```matlab
cd('path/to/code')
mvfp_a
```

The script creates the directory `outputs/student_minimal_mvfp` if it does not already exist. It writes PNG figures and tab-separated data files there. The main parameters are collected near the beginning of `mvfp_a.m`, including `par.u`, `par.v`, `par.bias`, `par.D`, `par.sigma1`, `par.sigma2`, `opts.T`, and the scan grids.

To run the network AND-gate scan:

```matlab
cd('path/to/code')
main
```

The default scan uses `N = 1000` units, 96 logarithmically spaced values of `D` from `0.001` to `0.3`, and 96 logarithmically spaced values of `g` from `0.01` to `10`. The calculation advances the system with a time step of `0.01` up to `Ttot = 7000`, so the default run can be computationally expensive.

## Outputs from `main.m`

By default, `main.m` writes output to the current working directory:

- `Al_N=1000_96_AND.mat`: MATLAB variables including the simulated probability arrays;
- `N=1000_DgP_96.dat`: tab-separated table with `log10(D)`, `g`, `log10(g)`, and the AND success probability;
- an open MATLAB figure showing the success probability as a heat map.

The output filenames and scan ranges are defined directly in `main.m`. Change them there before running a new experiment to avoid overwriting previous results.

## Outputs from `mvfp_a.m`

The MVFP script stores results in `outputs/student_minimal_mvfp`, including figures such as:

- `student_fig_mvfp_core_self_consistent_switch.png`;
- `student_fig_mvfp_mfpt_vs_p0.png`;
- `fig_PL_time_evolution.png`;
- `Figure_xP0_D0.03_g0.3.dat` and other exported data files generated by the script.

The exact set of files depends on the current version of `mvfp_a.m` and the numerical parameters selected at the top of the script.

## Reproducibility notes

- `main.m` initializes MATLAB's random-number generator with `rng(1)`.
- `trial_tot.m` also resets the generator with `rng(1,"twister")` for each call. Consequently, repeated calls with identical inputs are deterministic, but changing the scan structure or parallel execution settings can affect runtime and the order in which work is completed.
- `mvfp_a.m` is deterministic for fixed parameters because it evaluates numerical grids and quadratures without a stochastic simulation.
- Run each script from its code directory, or replace relative output paths with absolute paths before running it.
- The scripts currently write generated results into the working directory or the `outputs/` subdirectory. Keep generated files out of version control unless they are intentionally included as release artifacts.

## Model summary

The network simulation uses bistable units with local drift, additive noise, a bias term, and global mean-field coupling. The input sequence in `trial_tot.m` cycles through `+1`, `0`, and `-1` stages. A trial is marked successful when the simulated units satisfy the corresponding threshold condition at all sampled stages.

The MVFP script studies the corresponding mean-field density dynamics and frozen effective potential. It reports finite-time readout performance, steady-state solutions, potential profiles, branch structure, and directional MFPT diagnostics.
